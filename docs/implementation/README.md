# Implementation records

Files in this directory record milestone decisions, failed attempts, and the implementation state
at their stated date. They are historical engineering evidence, not current deployment or recovery
instructions.

Use the [PRD index](../prd/README.md) for current product authority and the
[operations index](../operations/README.md) for active hosted procedures. When an older record
mentions Render, a raw Droplet, GHCR/digests, managed load rehearsal, direct-production validation,
or `prepare-source`, the later PRD amendments and active runbooks supersede it.
